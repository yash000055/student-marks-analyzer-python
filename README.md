# Student Marks Analyzer Using Python
## Description :

This project analyzes student marks using Python.
It takes marks of five subjects as input, calculates the total marks and percentage, and assigns a grade based on the calculated percentage.

The program helps understand basic conditional logic and arithmetic operations in Python.

## Features :

-Accepts marks for five subjects

-Calculates total marks

-Computes percentage

-Assigns grade based on percentage

-Simple and beginner-friendly logic

-Command-line based execution

## Technologies Used :

-Python 3
